# FUTURE_CS_03
API Security Risk Analysis Report including identified risks, impact explanation
Step 1 — Evidence collection: You captured 5 screenshots covering the CI/CD shell script, the 405 HTTP error body, response headers, the raw HTTP message, and API timing data.
Step 2 — Risk analysis: Each piece of evidence was analysed to identify vulnerabilities — 5 risks were found, ranging from the critical 405 misconfiguration down to the medium-severity SSRF risk.
Step 3 — CVSS scoring: Each risk was scored using the industry-standard CVSS framework (7.5 down to 4.3), giving each finding an objective severity level.
Step 4 — Report documentation: Everything was compiled into a professional Word .docx file with 5 sections: executive summary, scope, full risk register, remediation roadmap, and conclusion.
Step 5 — GitHub README: A structured README was created with severity badges, a findings table, remediation timeline, and evidence sources — ready to publish alongside the report.
